## Outcome

The portable check previously regenerated committed Rust-derived JSON Schema and TypeScript DTO files before comparing them. That order repaired stale generated files and could hide drift. Validation now compares committed outputs directly and fails without rewriting them.

Evidence manifests require non-empty requirement, decision, gate, input, procedure, expected, observed, limitation, reviewer, and check records. Required strings must contain non-whitespace content. Timestamp fields use the JSON Schema `date-time` format; schema tests register semantic date-time validation and reject impossible calendar days, times, and offsets. Fixture validation rejects missing redistribution permission, license, provenance, or digest; mismatched digests; credential sentinels; common quoted JSON credential fields; and repository path escapes.
