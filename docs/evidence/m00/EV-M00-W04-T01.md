## Outcome

The portable check previously regenerated committed Rust-derived JSON Schema and TypeScript DTO files before comparing them. That order repaired stale generated files and could hide drift. Validation now compares committed outputs directly and fails without rewriting them. Evidence manifests now require non-empty requirement, decision, gate, input, procedure, expected, observed, limitation, reviewer, and check records, validate SHA-256 and timestamp forms, and reject empty identifiers. Fixture tests cover missing redistribution permission, license, provenance, and digest, digest mismatch, credential-like content, and repository path escape.
