## Acceptance criteria

- [ ] Activation attempt is durable before commit; only all-worker verified results become the recovery checkpoint.
- [ ] Restart verifies artifact completeness/digests/compatibility and selects last verified content, preserving candidacy distinction.
- [ ] Disk full/corruption/permission loss never creates a false durable success; missing valid recovery uses the adapter-proven failure behavior.

## Required tests and validation

- Pinned FreeBSD filesystem/lab: stop processes at each artifact/journal stage and restart with verified old and unverified newer bundles; assert selected identity and observed packet action.
- Corrupt manifests/checkpoints, truncate writes, change incompatible catalog/schema and remove dependencies; verify rejection and explicit no-usable-bundle behavior.
- Inject full disk/permission loss before attempt and verified-result persistence; compare acknowledgments, status and recovery records, documenting the tested power-loss model rather than treating rename as proof.
