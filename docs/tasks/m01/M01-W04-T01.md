## Deliverables

- Canonical serialization/manifest specification and independently authored digest/compatibility vectors.
- Version inventory for schema/compiler/evaluator/normalization/timezone/catalog/data/capabilities and nonsemantic exclusions.

## Acceptance criteria

- [ ] Set/map ordering, numeric/string encoding and stable enum IDs are specified; explicit priority meaning is preserved.
- [ ] The bundle digest excludes its own field and only explicitly documented nonsemantic build/audit metadata.
- [ ] Local paths, machine/CPU discovery and random build IDs cannot affect semantic identity.
- [ ] Unsupported required capabilities and incompatible dependency/version combinations reject preparation; a hash alone never proves correctness.

## Required tests and validation

- Review golden serialization vectors for unordered input permutation versus priority changes; the former has identical bytes and the latter changes meaning/identity.
- Create compatibility tables with missing catalog/data/normalization versions and an unsupported required capability; each has an explicit rejection code.
- Have a reviewer recompute a small manifest digest from the documented canonical bytes independently of the compiler.
