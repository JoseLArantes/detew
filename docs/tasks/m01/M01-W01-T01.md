## Deliverables

- Domain/wire DTOs, structured semantic errors, context/decision/outcome types and versioned capability manifest.
- Documented schema subset, exact counter/timestamp/unknown-state conventions and validation constraints.
- Versioned time-health/UTC+boot-monotonic, source eligibility/deadline, and operation ID/idempotency/progress/error interfaces for M06/M07 integration.

## Acceptance criteria

- [ ] Stable IDs are separate from display text; revisions/generations/sequences/large counters are canonical decimal strings backed by checked integer parsing.
- [ ] Unknown/pending/unsupported/invalid/stale/completion and verdict/enforcement outcomes are distinct typed facts.
- [ ] Explicit evaluation inputs include bundle, evidence/attribution/time/schedule/override context; no ambient timezone, SQL or network read determines policy.
- [ ] Domain/policy types forbid unsafe code and excluded dependencies; unknown write fields, dangling references and invalid priorities produce stable field-addressed errors.
- [ ] Time and eligibility inputs identify trust, source validity and expiry; operation state distinguishes draft/saved/preparing/mixed/applied/failed with stable operation identity and no circular dependency on M06/M07 implementations.
