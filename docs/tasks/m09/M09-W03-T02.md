## Acceptance criteria

- [ ] Campaigns cover packet framing/reassembly/native shim, normalization/data admission/configuration imports and local message envelopes at their real trust boundaries.
- [ ] Malformed/truncated/oversized input cannot create uncontrolled memory/time use, unwinding across C, stale pointer ownership, guardrail bypass, or unauthorized mutation.
- [ ] Native allocations/lifetimes and process crash consequences are reviewed; a Rust wrapper is not represented as isolating native memory faults.
- [ ] Every observed crash/semantic mismatch has a reproducer, disposition, and repaired regression evidence or remains a release blocker.
- [ ] Unavailable native sanitizer support is reported; portable fuzzing supplements and never replaces FreeBSD replay/adapter evidence.

## Required tests and validation

- Pinned portable/native harnesses from M00/M02: execute declared seed corpora and independently generated adversarial mutations for the recorded time/iteration budgets; retain environment and actual coverage/crashes.
- Where supported, run native sanitizer builds of the C shim/classifier and allocator measurements; replay every actionable native reproducer on the exact supported FreeBSD build.
- Review native allocation/free/error contracts and replay semantic property counterexamples through shared evaluator and integration path; verify repaired behavior and bounded resource use under repeated input.
