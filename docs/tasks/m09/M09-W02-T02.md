## Deliverables

- Reproducible normal/adversarial-load failure matrix with restoration procedures.
- Status/record loss intervals and observed adapter failure-action report.
- Blocking defect inventory with root cause and independently reproduced repair evidence.

## Acceptance criteria

- [ ] Engine death, interface reset, overload, capture failure and reboot follow only the adapter-proven behavior and expose real coverage/recovery limitations.
- [ ] Controller/UI/activity/download death leaves the eligible verified bundle operating; category expiry and override/schedule transitions still act engine-locally.
- [ ] Worker stalls/mixed generations, corrupted/full/permission-denied storage and interrupted writes cannot report fully applied or promote an unverified candidate.
- [ ] Queue pressure and reporting loss remain distinct from packet enforcement failure; event gaps and incomplete replay are disclosed.
- [ ] Active blocked state is never silently evicted and converted into an ordinary allow; overload/admission/provisional limits stay bounded and observable.

## Required tests and validation

- Pinned native lab at normal and excess offered load: terminate each daemon/worker, reset interfaces and disable capture; independently observe client/server traffic, adapter action, status timestamps and management access.
- Inject disk full, corrupted artifacts/journal/activity DB, interrupted commit, stale concurrent edits, expired data and lost/jumped clocks; verify durable accepted state and explicit recovery.
- Saturate activity queues and stop the activity daemon while changes reconsider active/idle flows; verify enforcement independence, nonblocking packet work, loss intervals, and no old allow after invalidation.
