## Acceptance criteria

- [ ] Both directions, VLAN/realm separation, NAT original-client attribution, pf denial and reinjection ordering are verified; Detew allow never overrides pf deny.
- [ ] HTTP/TLS/QUIC, segmentation/fragmentation, absent SNI, ECH/GREASE, direct IP, shared CDN, resumed/early-data/midstream and encrypted/tunnel cases retain separate evidence dimensions and uncertainty.
- [ ] Supporting resolver/known tunnel controls do not enforce traffic-policy drops in observe mode; transport denial never asserts fallback, decryption, or application success.
- [ ] Late prohibited evidence stops the tracked flow within the published bound with earlier forwarded bytes disclosed.
- [ ] Each block has a stable deciding reason and confirmed or explicitly failed/unknown enforcement outcome; unavailable evidence is never invented.

## Required tests and validation

- Replay malformed, fragmented, coalesced, ECH/GREASE and preattachment active flows; compare reviewed evidence expectations against independent packet/client observations.
