## Deliverables

- Versioned checksummed journal/checkpoint implementation and immutable same-filesystem artifact installation.
- Explicit corruption/full-disk/permission failure handling with active/previous/candidate recovery references.

## Acceptance criteria

- [ ] Flush/rename/directory-sync ordering has tested durability semantics; candidate paths are controlled IDs rather than client paths.
- [ ] Corrupt/incompatible/missing artifacts cannot become verified active simply because a saved pointer refers to them.
- [ ] Active and recovery bundles remain intact while bounded failed/candidate content can be quarantined; no unbounded artifact growth.

## Required tests and validation

- Pinned FreeBSD storage harness: kill at each write/flush/rename/checkpoint boundary, recover, and compare complete bytes/digests/stages to independent expected journal transitions.
- Corrupt headers/checksums, truncate records, replace paths with invalid ownership and present incompatible artifacts; verify rejection without promoting candidates.
- Inject full disk, directory permission loss and simultaneous reporting pressure; test refusal/recovery and document exact power-loss/corruption limits without claiming hardware-proof durability.
