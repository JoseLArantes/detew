## Deliverables

- Single native-authorized mutation boundary used by UI/API/import/console/correction writers.
- Lock/re-read/expected-revision/reserve/native-save/snapshot transaction recovery contract and digest drift detection.

## Acceptance criteria

- [ ] The lock covers re-reading revision/model through native save; competing stale editors receive changed-object conflicts.
- [ ] A fresh exact integer revision is reserved durably before save; reservation failure refuses the write and save failure may leave a harmless gap.
- [ ] Reserved, saved and applied remain distinct; daemons never rewrite appliance XML or maintain an independently editable policy database.

## Required tests and validation

- Pinned native model/journal lab: race all supported writer types with identical/different expected revisions; verify one accepted intent and deterministic conflicts without lost update.
- Exercise decimal counters beyond JavaScript safe integer, mismatched lineage/digest, unexpected model edits and unavailable reservation IPC; ensure refusal/reconciliation and no number rounding.
- Terminate between lock/reserve/save/snapshot and inject disk full/permissions; inspect native model plus journal on recovery, confirming counter gaps never imply saved/applied state.
