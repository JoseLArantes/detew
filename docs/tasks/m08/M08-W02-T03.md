## Deliverables

- Device/group/network assignment reorder/diff and scoped override replacement/expiry forms.
- Rollback/restoration preview with explicit configuration/data/catalog dependency choice and operation confirmation.

## Acceptance criteria

- [ ] Assignment UI shows explicit precedence without hidden selector-type preference or silent reorder.
- [ ] Temporary override asks narrow scope/reason/expiry, shows existing replacement and return profile; uncertain attribution/time prevents false validity.
- [ ] Rollback is a new reviewed revision/activation with missing/expired dependencies visible; reconnect/session-restoration limits are explained.

## Required tests and validation

- Native browser/runtime journey: assign conflicting selectors, create/replace a narrow override across timezone/expiry and roll back to chosen compatible data; compare canonical winner and traffic.
- Attempt duplicate priority, ambiguous device, broad exception, untrusted time and absent/incompatible rollback artifact; confirm structured validation, mapping and draft preservation.
- Expire an override with browser/control unavailable and interrupt rollback/apply; reconnect and verify actual return profile, distinct desired/active state and recovery.
