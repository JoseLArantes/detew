## Deliverables

- Privacy/retention/quota/collection-disabled settings integrated with activity writer and completeness status.
- Bounded deletion and canonical configuration/correction/dependency export/import with visible site/device mappings and optional history handling.

## Acceptance criteria

- [ ] Default excludes packet/browsing-body retention and telemetry; hostname/device metadata disclosure appears before detailed activity collection.
- [ ] Seven-day/512-MiB values remain proposed until measured freeze; configured quotas bound DB/WAL/export/deletion work and collection-disabled does not stop filtering.
- [ ] Deletion scope distinguishes activity from bounded policy audit; config/corrections/dependencies, runtime evidence/history, third-party data and keys are separate.
- [ ] Export/import requires permissions/review and excludes unapproved data redistribution/keys by default; no export sends data anywhere.
