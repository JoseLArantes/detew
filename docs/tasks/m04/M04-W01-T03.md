## Deliverables

- Native writer interruption/concurrency/restore report and minimal recovery test seams.
- Restore/import lineage/revision rebasing procedure and corrupted/disk-full journal outcomes.

## Acceptance criteria

- [ ] Restored older native revisions are rebased through the same native writer; old intent cannot roll back the durable local high-water mark.
- [ ] A new installation or unrecoverable journal reset establishes explicit new lineage; identity/revision history is not falsely continuous.
- [ ] No atomic transaction is claimed across reservation/native save/snapshot/worker state; each interruption has a reconciled status and documented retry.
- [ ] Corrupt, partial, incompatible and disk-full input/journal failures reject/recover explicitly without silently writing whole-appliance XML or reporting applied state.

## Required tests and validation

- Restore a synthetic old revision over newer native intent in the isolated lab, race a second writer, and verify new reserved/saved revision plus conflict handling.
- Inject interruption at each reservation/save/snapshot boundary, truncated/corrupt journal and disk-full temporary filesystem; reboot and inspect desired/snapshot/status consistency.
- Reconstruct a new installation/unrecoverable journal-reset scenario and verify lineage is changed explicitly; unrelated host configuration and secret exclusions remain intact.
