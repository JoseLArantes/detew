## Deliverables

- Minimal native status/model/validate/save/operation endpoints backed by the one writer and authenticated control bridge.
- Admin/viewer/security/concurrency API conformance report at the exact host patch revision.

## Acceptance criteria

- [ ] Admin can perform permitted protected writes; viewer reads but cannot mutate through direct API, forged UI requests or alternate methods.
- [ ] Expired sessions, missing/invalid CSRF and unsupported mutation methods reject without native save or privileged action.
- [ ] Client-supplied actor/role claims are ignored/rejected; authoritative host session/ACL determines attribution.
- [ ] Stale writes return useful conflict context and preserve draft inputs; operation reads/status cannot imply live protection from a prototype.

## Required tests and validation

- Execute a request matrix on the isolated native host for admin/viewer/unauthenticated/expired session, valid/missing/forged CSRF and GET/POST/PUT/DELETE/unsupported methods; inspect native desired revision/actions before and after.
- Send oversized/unknown-field/invalid-reference inputs plus forged role/actor, remote-schema references and injection text; assert bounded stable errors and no unintended state change.
- Issue concurrent same-revision saves and reconnect to the resulting operation; verify one winner, stable operation identity, expected conflict and session-safe error display inputs.
