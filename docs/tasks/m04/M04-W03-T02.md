## Deliverables

- Typed native request-helper adapter, TanStack query/status/pagination and operation polling prototype.
- Strict loading/stale/error/conflict/permission/reconnect fixtures using accepted native API shapes.

## Acceptance criteria

- [ ] Native transport preserves host CSRF/session/ACL behavior and validates generated response shapes without implementing a second policy algorithm.
- [ ] Decimal revisions/counters remain exact; queries never compare revision strings lexicographically or coerce unsafe numbers.
- [ ] Mutation retries obey idempotency and never silently resubmit/overwrite stale edits; operation identity survives reconnect.
- [ ] Refresh failure removes present-tense health claims and shows last confirmed timestamp; local drafts/filter context survive errors/conflicts.

## Required tests and validation

- Against the isolated native endpoints, perform save/read/operation flows under admin/viewer and session expiry; inspect actual protected request headers/methods and write effects.
- Use controlled response/error fixtures for counter values above 2^53, malformed/unsupported DTO, timeout, stale status, mixed generation and conflict; verify exact display/state/draft preservation.
- Disconnect/reconnect during an operation and replay an authorized idempotent request per contract; verify no duplicate save and stable operation tracking.
