## Deliverables

- Minimal native XML model/storage mapping for profiles, assignments, guardrails and initial revision metadata.
- Generated JSON snapshot bridge and native/Rust/schema/TypeScript round-trip fixtures.

## Acceptance criteria

- [ ] Host model values map losslessly to authoritative domain/wire types, stable IDs and exact decimal-string revisions.
- [ ] Native XML is the sole desired-state authority; Rust daemons neither parse/write full config.xml nor persist an alternate desired model.
- [ ] Invalid/dangling/unknown writes are rejected through authoritative Rust semantic validation with stable native field-addressed feedback.
- [ ] Inventory observations and apply progress are not persisted as learned desired configuration; snapshot versions/digests remain explicit derived state.

## Required tests and validation

- On the pinned isolated OPNsense host, save/export valid synthetic model cases and round-trip through Rust/schema/TypeScript; compare IDs, priority, null/optional and counters above 2^53.
- Attempt invalid references, duplicate enabled priorities, unsupported fields and malformed native values through the bridge; verify no authoritative save occurs.
- Inspect desired-state write paths and file permissions; demonstrate generated snapshots can be rebuilt from native intent without SQL/daemon authority.
