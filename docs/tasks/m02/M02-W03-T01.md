## Acceptance criteria

- [ ] Library, headers, bindings, catalog mapping and features are paired exactly; an incompatible ABI/catalog is rejected before inspection.
- [ ] Worker contexts and per-flow state have one owner with paired allocation/free; domain types contain no native pointer or borrowed packet memory.
- [ ] Packet lengths and output/string bounds are validated; unsupported/error statuses are typed and Rust unwinding cannot cross C.
- [ ] Native crashes remain inspection-process failures; the wrapper does not claim process isolation or universal memory safety.

## Required tests and validation

- Build using exact pinned FreeBSD compiler/ports inputs; exercise known HTTP/TLS fixture observations and compare pinned catalog IDs rather than display text.
- Run handle allocation/free/reuse/error sequences, zero/truncated/oversized packet inputs and invalid output lengths through the shim; verify bounded rejection and no pointer escape.
- Simulate a wrapper panic/native error in supported test seams and review boundary behavior; ABI mismatch must fail loading rather than reinterpret observations.
