## Deliverables

- Control-side importer/compiler using shared normalization, sort/deduplication and FST metadata split.
- Versioned artifact format and valid/invalid import fixtures, with explicit temporary disk/memory caps.

## Acceptance criteria

- [ ] Input trust/license/schema/taxonomy checks precede artifact construction; entries retain exact/subdomain semantics, source provenance and label unions.
- [ ] Lengths, encodings, record counts, decompression and external-sort temporary resources are bounded; traversal/links/bombs cannot escape the processing sandbox.
- [ ] Identical admitted inputs/versions produce identical artifacts independent of input order/duplicate rows/local paths.
- [ ] The packet lookup representation is preloaded validated bytes plus metadata; no SQL/network/file lookup is introduced into decision evaluation.

## Required tests and validation

- Compile independent synthetic sources with duplicates, Unicode equivalents, multiple providers/labels and deceptive suffix entries; verify exact expected normalized keys/provenance/labels.
- Process invalid encodings, oversized records, traversal/link archives, high-expansion compressed input and quota exhaustion in an isolated temp directory; verify bounded rejection and cleanup.
- Compile permuted identical inputs twice with declared pinned tools and compare artifact bytes/digests; preserve semantic subdomain distinctions.
