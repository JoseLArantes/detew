- [ ] Intervals are half-open in the IANA site timezone; overnight/repeated/skipped local times follow PRODUCT exactly.
- [ ] Default unreliable time activates all configured scheduled block overlays; configured last-trusted-state alternative is explicit and warned.
- [ ] Controller loss cannot freeze future schedule transitions, and permanent controls remain active.
